# SignBridge

A real-time AI-powered Sign Language Translation System that recognizes sign language from a webcam, converts it into text, and generates natural speech.

---

## 🎯 Project Goal

SignBridge aims to bridge the communication gap between deaf or hard-of-hearing individuals and hearing people using Computer Vision, Deep Learning, and Natural Language Processing.
